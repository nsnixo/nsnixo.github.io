Before going live

  • Set up a backend and database so customer orders from all devices reach the owner dashboard.
  • Add real owner authentication and server-side role checks.
  • Integrate a supported payment gateway using server-side secrets and signed webhook verification.
  • Configure support contact, privacy policy, terms, refund policy, and final prices.
  • Never store customer passwords, card PINs, or OTPs.
